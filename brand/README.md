# Nabda brand mark

The mark is a single guarded route: it starts as a pulse, bends into an abstract **N**, and terminates at a warm delivery point. It is intentionally compact enough for a tray icon and calm enough for the product interface.

## Files

- `nabda-mark.svg` — standalone symbol for apps, favicons, and avatars.
- `nabda-wordmark.svg` — horizontal English lockup.
- `concepts/` — original raster explorations generated during the design process.

## Palette

- Charcoal: `#17211F`
- Teal: `#59B7A4`
- Amber: `#E5A84B`
- Paper: `#F8FAF8`

Use the symbol without altering its proportions. Keep clear space equal to the amber endpoint diameter. The mark must not be presented as, or combined with, the branding of an external SMS provider.

## Third-party phone silhouette

The neutral Android phone frame is adapted from a Vecteezy smartphone vector supplied with the project. The manufacturer wordmark was removed so the interface does not imply affiliation. Attribution: **Vecteezy.com**. The supplied Vecteezy terms remain applicable to that silhouette.
