SETUP / FIVE STEPS

Connect the official Android app without local pairing.

Desktop uses the hosted provider API. It does not install a phone agent, open a LAN listener, create a device token, or ask for a local QR session.

1. Provider account

Create or sign in to your httpSMS account.

2. Official Android app

Install it from the provider documentation and complete its permissions.

3. Account API Key

Copy the full account key from settings, not a phone-only key.

4. Registered From

Enter the phone number in E.164 format, such as +2189XXXXXXXX.

5. Save and Test Connection. The test reads /v1/users/me; it does not send an SMS. Only deliberately adding a message to the queue can reach the send endpoint.
