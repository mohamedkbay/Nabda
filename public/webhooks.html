Event contract

A small envelope with enough context.

Each event has a stable ID, event type, creation time, and current public message data. Store the event ID to reject duplicate delivery effects.

HMAC-SHA256 · v1

Verify before parsing or processing.

Read x-nabda-timestamp and compute HMAC-SHA256 over timestamp + "." + rawBody. Compare the result to the hex digest after the v1= prefix in x-nabda-signature.

Preserve the raw bytes. Re-serializing JSON can change whitespace or key order and invalidate a correct signature.

Verification order

  1. Read the raw request bytes and signature headers.
  2. Reject a missing, malformed, or stale timestamp.
  3. Compute the v1 HMAC with the endpoint secret.
  4. Compare decoded digest bytes in constant time.
  5. Parse JSON and deduplicate by event ID.
Node.js · Nabda v1
import { createHmac, timingSafeEqual } from "node:crypto";

function validSignature(rawBody, timestamp, provided, secret) {
  if (!Buffer.isBuffer(rawBody)) return false;
  if (!/^\d{10,}$/.test(timestamp ?? "")) return false;
  const signedAt = Number(timestamp);
  const now = Math.floor(Date.now() / 1000);
  if (!Number.isSafeInteger(signedAt) || Math.abs(now - signedAt) > 300) {
    return false;
  }
  if (!provided?.startsWith("v1=")) return false;
  const providedHex = provided.slice(3);
  if (!/^[a-f0-9]{64}$/i.test(providedHex)) return false;

  const expectedHex = createHmac("sha256", secret)
    .update(Buffer.from(`${timestamp}.`, "utf8"))
    .update(rawBody)
    .digest("hex");
  const expected = Buffer.from(expectedHex, "hex");
  const actual = Buffer.from(providedHex, "hex");
  return expected.length === actual.length &&
    timingSafeEqual(expected, actual);
}

Delivery behavior

Assume retries. Design for them.

Network errors, timeouts, and non-2xx responses are recorded and may be retried until the delivery reaches its configured attempt limit.

Return 2xx quickly

Verify and persist the event, then move heavier work to your own queue.

Deduplicate by event ID

Store the event ID under a unique constraint. Return success for a repeated event without repeating side effects.

Keep secrets rotatable

Read secrets from a protected server environment. In this MVP, webhook provisioning and rotation are administrative, not public API operations.

Endpoint checklist

A secure receiver has clear boundaries.

HTTPS

Use a trusted TLS endpoint outside tests. Nabda blocks private and reserved destinations.

Raw body

Capture request bytes before a body parser alters the payload.

Fast response

Persist then return 2xx; move downstream work to your queue.

Safe logs

Log event IDs and outcomes, not secrets or complete recipient payloads.

Test the full event path in Mock mode.

Create a message, let the worker process it, and verify the signed event before considering a live provider.
