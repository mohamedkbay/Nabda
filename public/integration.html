INTEGRATION / LOCAL-FIRST

Your desktop, the hosted API, and the official Android app.

httpSMS Desktop is an independent, unofficial client. Contacts, opt-outs, campaigns, queue state, and history remain in local SQLite. Only deliberate provider operations leave the computer over HTTPS.

Follow the setupRead provider setup

THE ROUTE

One explicit path with clear trust boundaries.

1. Local workspace

Electron keeps business records and the durable queue on this computer.

2. Encrypted credential

The Account API Key is protected by Electron safeStorage and never stored in SQLite.

3. Hosted API

The main process calls only https://api.httpsms.com/v1.

4. Official phone app

The provider coordinates delivery with its Android application and your registered SIM.

NO LOCAL PAIRING

No custom APK, QR session, phone token, or LAN listener.

Install and sign in to the official Android application according to the provider documentation. Desktop needs the full Account API Key and registered From number.

Test Connection is read-only. It calls GET /v1/users/me and never calls the send endpoint.
