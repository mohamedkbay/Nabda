OFFICIAL API / DESKTOP BOUNDARY

A small, auditable provider surface.

The desktop main process authenticates to the hosted httpSMS API with x-api-key. Credentials never enter the renderer, URLs, SQLite, backups, or logs.

Operations used in phase one

MethodEndpointPurpose
GET/v1/users/meRead-only credential test
POST/v1/messages/sendSubmit a deliberate queued message
GET/v1/messages/:idPoll delivery state

Send body

Desktop sends content, from, to, and request_id. It adds send_at and encrypted only when selected.

No blind retry. If the send outcome is ambiguous, Desktop records manual review instead of risking a duplicate SMS.
POST /v1/messages/send
