Unofficial client
  1. 1
    ثبّت تطبيق httpSMS الرسمي

    نزّل أحدث APK من صفحة الإصدار الرسمية.

    فتح رابط التطبيق
  2. 2
    سجّل الهاتف بالطريقة الرسمية

    سجّل الدخول من التطبيق واتبع طريقة الحساب أو Phone API Key الرسمية.

  3. 3
    انسخ Account API Key

    استخدم مفتاح الحساب الكامل من Settings، وليس Phone API Key.

    فتح Settings
  4. 4
    أدخل From بصيغة E.164

    مثال: +2189XXXXXXXX. يجب أن يطابق الرقم المسجّل.

  5. 5
    احفظ ثم اختبر الاتصال

    الاختبار يقرأ ملف الحساب عبر /users/me ولا يرسل SMS.
